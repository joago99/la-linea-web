# La Línea Web

Dashboard económico de Chile vs el mundo (1958–2026).
Fuentes: Banco Central de Chile (BCCh), INE, Banco Mundial.

Sitio web estático con HTML/CSS/JS vanilla. Desplegado en GitHub Pages.

## Estructura

- `index.html` — Landing principal
- `empresa.html` — Página empresa
- `servicios.html` — Servicios
- `capsula-servicios.html` — Cápsula de servicios
- `lalinea.html` — La Línea (dashboard)
- `bombas-hormigon/` — Cotizador bombas hormigón (subproyecto)
- `cerezas/` — Análisis cerezas
- `data/` — Datos procesados
- `vendor/` — Librerías third-party
- `logo.png` — Logo

## Despliegue

GitHub Pages desde la rama `main`.

## Fuentes de datos

- Banco Central de Chile (BCCh) — Indicadores macroeconómicos
- INE — Estadísticas demográficas y sociales
- Banco Mundial — Comparativas internacionales
